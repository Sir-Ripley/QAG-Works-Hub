# QAG Works Hub

Rodney Ripley's portfolio landing page — https://qag-works-hub.vercel.app/

Single-file dark-cosmic landing page (`index.html`, no build step) linking
the project portfolio: QACTS, MeditationMedicine, QAG Nexus, Kinetics Lab,
Virology Demo, plus accomplishments, roadmap, and contact links.

All outbound project links use bare root production URLs so they always
serve the latest deployments.

## Deploy

Git-connected Vercel project `qag-works-hub` — push to `main` auto-deploys.
No build command; output directory is the repo root.

To make the page public: Vercel dashboard → project → Settings →
Deployment Protection → disable (new projects default to SSO-gated).
